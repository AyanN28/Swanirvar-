# Swanirvar Backend-Only Package

This archive contains the backend and backend-served web assets from the PortalReady Swanirvar v1.1.2 artifact available in the conversation.

Included:
- FastAPI backend
- deterministic 7D engine
- evidence/state data used by the backend
- Gemini adapter with fallback
- Bhashini adapter
- OSM/OSRM live-source adapters
- market adapter
- HTML/PDF report generation
- backend-served web assets

Excluded:
- React frontend
- node_modules
- large Drive-wide datasets/models/checkpoints

IMPORTANT:
The exact later Drive-current backend contains additional edits made after this uploaded PortalReady artifact. Use the included Colab notebook to package the exact current Drive backend when you run it. Do not treat this baseline archive as a byte-for-byte snapshot of the later Drive state.
